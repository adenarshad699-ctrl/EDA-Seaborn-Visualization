# Exploratory Data Analysis with Seaborn

A hands-on data visualization project completed as part of a data science training course (Lecture 04).

## About
This notebook explores the `tips` dataset (restaurant bills and tips) using Seaborn and Matplotlib.

## Visualizations Covered
- Line plot
- Bar plot
- Count plot
- Histogram (with KDE)
- KDE plot
- Box plot
- Violin plot
- Strip plot
- Correlation heatmap

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
